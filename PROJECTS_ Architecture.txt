Пайплайн обучения (train.py):
    Preprocessing → Ridge / Lasso / ElasticNet
                  → LightGBM / XGBoost / CatBoost  (early stopping, OOF)
                  → Neural Net MLP                  (опционально, если torch)
                  → Stacking Ridge мета-леарнер
                  → submission_stacking.csv

Артефакты после train.py (models/):
    *_models.pkl            — fold-модели каждого алгоритма
    stacking_meta.pkl       — обученный Ridge мета-леарнер
    model_names.pkl         — порядок моделей для стекинга
    oof_predictions.csv     — OOF предсказания + residuals
    cv_scores.json          — CV RMSLE всех моделей
    feature_importances.csv — усреднённая важность признаков (бустинги)

Инференс (predict.py):
    Загружает артефакты из models/ → прогоняет test.csv через тот же
    preprocessing → генерирует submission без переобучения.
